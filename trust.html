Trust Center

How Link Healthcheck for Jira handles your data, security and privacy.

Runs on AtlassianBuilt on Atlassian Forge. No servers of our own.
No data leaves AtlassianNo external calls, no analytics, no tracking.
No personal data storedNo user fields are read: no assignee, reporter, name or e-mail.
You stay in controlChanges only after your confirmation, made with your own Jira account.

Data handling

Hosting100% Atlassian Forge infrastructure. The app qualifies for the “Runs on Atlassian” trust signal.
Jira data readFor the project you open: key, summary, type, status, created and updated dates, parent and issue links. Processed in memory during the scan, not stored.
Data storedIn Forge storage, per project: app settings, the findings you chose to ignore (check name and issue key) and a 30-day score history (date, score, number of problems).
Changes in JiraOnly after a click and an explicit confirmation: removing an obsolete “blocks” link or moving a finished epic to Done. Each change runs as the current user and appears in the issue history.
Permissions (scopes)read:jira-work, write:jira-work, storage:app. Nothing else.
Third partiesNone. No sub-processors other than Atlassian, which hosts Forge. Nothing is sold or shared.
Data residencyData stays in your site's Forge storage, managed by Atlassian.
Retention and deletionKept while the app is installed. Deleted by Atlassian under Forge rules when the app is uninstalled. Admins can clear ignored findings at any time in Settings.

Security

AuthenticationHandled by Atlassian (Forge). The app stores no passwords, tokens or secrets.
AuthorizationAdmin-only actions are re-checked on the server with Jira's permission API. Write actions are limited to the open project.
EncryptionProvided by Atlassian: Forge storage is encrypted at rest and all traffic uses HTTPS.
LogsTechnical error messages only, with no personal data.
TestingAutomated unit and QA tests must pass before every production release, plus dependency scanning (npm audit) and manual tests on a separate test site.
DependenciesOfficial Atlassian Forge packages and React only, kept up to date.
Service statusThe app runs entirely on Atlassian Forge, so its availability follows Atlassian Cloud. Live status: status.atlassian.com.
Incident responseWe follow Atlassian's Marketplace security incident process and notify Atlassian and affected customers.
